# Company wordmarks

The social rail uses inline LinkedIn, GitHub, X, and Instagram SVGs from [Bootstrap Icons](https://github.com/twbs/icons/tree/main/icons). They inherit the page text color. Their MIT license is included in `Bootstrap-Icons-LICENSE.txt`.

The Letterboxd mark is from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/letterboxd.svg), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

Original vector wordmarks, saved locally for the Transcript prototype. Paths are retained; visible paint is normalized to black. The page uses CSS inversion for white marks in dark mode. These assets do not use web fonts, raster images, or external resources.

Sources:

- `palantir.svg`: the `logoSvg` wordmark embedded in the public [Palantir homepage](https://www.palantir.com/).
- `rippling.svg`: the primary inline navigation wordmark on the public [Rippling homepage](https://www.rippling.com/). A viewBox matching its original width and height was added for responsive scaling.
- `afterquery.svg`: the official [AfterQuery SVG wordmark](https://www.afterquery.com/brand/afterquery-logo.svg), linked by its homepage.
- `raymond-james.svg`: the [Raymond James full wordmark](https://companieslogo.com/img/orig/RJF_BIG-861e6392.svg?t=1720244493), from the [CompaniesLogo archive](https://companieslogo.com/raymond-james/logo/). The official media server was unavailable during retrieval.

The respective companies retain ownership of their names and marks. Palantir and Rippling are identified as incoming roles in the nearby experience ledger and logo link titles.
